# ブレハン

Android端末内の写真を自動スキャンし、手ブレやピンボケなど「ぼけている写真」を検出するアプリ。各写真にシャープネススコア（0〜100）を付与し、不要な写真を見つけやすくする。

## 機能

- 端末内の全写真を一括スキャンし、シャープネスを判定
- スコア順（低い順）にギャラリー表示し、ぼけている写真を上に表示
- サムネイルにスコアをオーバーレイ表示

### スコアの目安

| スコア | 意味 |
|--------|------|
| 0〜30 | かなりぼけている（削除候補） |
| 31〜60 | やや甘い |
| 61〜100 | シャープ（問題なし） |

## 判定ロジック

OpenCV の Laplacian フィルタを使用。画像をリサイズ（長辺800px）→グレースケール変換→ラプラシアン適用→分散値を算出し、シグモイド関数で0〜100にマッピングする。EXIFデータは使用せず、ピクセルデータのみで判定する。

## 技術スタック

- Kotlin / Jetpack Compose
- OpenCV Android SDK（画像処理）
- MediaStore API（写真取得）
- Kotlin Coroutines（非同期スキャン）

